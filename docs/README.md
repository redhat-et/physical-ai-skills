# Contributor docs

Start here if you're adding a new skill or script to this repo.

- **[adding-a-skill.md](adding-a-skill.md)** — walkthrough of the directory
  structure, the `SKILL.md` frontmatter, the script header contract, and
  how CI checks both.
- **[templates/SKILL.md.template](templates/SKILL.md.template)** — copy
  this to start a new skill.
- **[templates/script.py.template](templates/script.py.template)** — copy
  this to start a new CLI script.

See the top-level [README.md](../README.md) for what this repo is and how
it's consumed (`npx skills add`, agentskills.io).
